# 여명티켓 이미지형 랜딩페이지

비상티켓.com의 실제 규격과 섹션 구성을 기준으로 새 콘셉트로 제작한 정적 랜딩페이지입니다.

## 기준 규격

- 콘텐츠 폭: 1122px
- 헤더 높이: 93px
- 첫 이미지: 1122 × 1683px
- 이후 이미지 6장: 각각 1122 × 1402px
- 첫 상담 영역: 413px
- 마지막 상담 영역: 485px

`index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.

## 상담 채널

- 기준 페이지의 카카오톡 위치 → 전화
- 기준 페이지의 전화 위치 → 카카오톡
- 전화 버튼 문구는 기존 LINE 상담 링크로 연결
- 카카오톡 버튼은 상담 채널 링크로 연결
